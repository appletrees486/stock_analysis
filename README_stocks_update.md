# 종목 정보 업데이트 가이드

## 개요
JSON 파일의 종목 정보를 MySQL 데이터베이스 `stocks` 테이블에 업데이트하는 스크립트입니다.

## 파일
- `update_stocks_from_json.py` - MySQL 데이터베이스용 종목 정보 업데이트 스크립트

## JSON 파일 구조
```json
[
    {
        "회사명": "동화약품(주)",
        "종목코드": "000020",
        "마켓 구분": "KOSPI"
    }
]
```

## 사용법
```bash
python update_stocks_from_json.py
```

## 주요 기능
- **데이터 변환**: JSON → MySQL 테이블 형식
- **배치 처리**: 1000개씩 처리하여 성능 최적화
- **중복 처리**: `ON DUPLICATE KEY UPDATE` 사용
- **로깅**: 상세한 진행 상황 기록

## 주의사항
1. **데이터베이스 연결**: `database_config.py` 설정 확인
2. **테이블 존재**: `stocks` 테이블이 미리 생성되어 있어야 함
3. **권한**: 데이터베이스 쓰기 권한 필요

## 오류 해결
- **JSON 파일 오류**: 파일 경로와 인코딩 확인
- **DB 연결 오류**: 서버 상태와 연결 정보 확인
- **테이블 오류**: 테이블 스키마와 권한 확인
