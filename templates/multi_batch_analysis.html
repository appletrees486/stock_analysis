여러 종목 리스트 파일을 업로드하여 순차적으로 분석

📋 종목 리스트 파일 형식

텍스트 파일(.txt)에 종목코드를 한 줄에 하나씩 입력하세요:

079160
035760
311690
000120

💡 작성 팁

  • 6자리 종목코드만 입력 (예: 005930)
  • 한 줄에 하나의 종목코드
  • 빈 줄이나 주석은 무시됩니다
  • 파일당 최대 100개 종목까지 처리 가능

🎯 자동 감지 기능

파일명에 키워드를 포함하면 자동으로 설정됩니다:

📊 차트 유형
  • 일봉: 파일명에 "일간", "daily", "day" 포함
  • 주봉: 파일명에 "주간", "weekly", "week" 포함
  • 월봉: 파일명에 "월간", "monthly", "month" 포함
📈 거래타입
  • 거래대금: 파일명에 "거래대금", "volume" 포함
  • 거래율: 파일명에 "거래율", "turnover" 포함

예: "stock_list_일간_거래량.txt", "daily_volume_stocks.txt", "주간_거래률_분석.txt"
